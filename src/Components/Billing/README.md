# Billing Components

Reusable POS billing layout primitives inspired by the reference counter screen.

Use these classes for billing screens:

- `epos-billing-shell`
- `epos-billing-topbar`
- `epos-billing-products`
- `epos-billing-checkout`
- `epos-billing-product-grid`
- `epos-billing-product-card`
- `epos-billing-panel`

The active app implementation uses the feature page in `src/main/features/billing`.
